# MultiShop - Frontend

## Este repositorio está destinado a MultiShop, como TP para la facultad y para seguirlo más adelante

Tienda online multirrubro desarrollada en React, que ofrece una amplia variedad de productos (moda, tecnología, accesorios y más) obtenidos dinámicamente desde una API.

## Descripción

La aplicación permite explorar el catálogo de productos de forma dinámica, ver el detalle de cada artículo, gestionar un carrito de compras interactivo con persistencia de datos y simular el proceso de compra mediante un formulario controlado.

## Tecnologías utilizadas

- React (Vite)
- React Router DOM
- React-Bootstrap / Bootstrap 5
- JavaScript (ES6+)
- CSS / CSS Modules
- FakeStore API
- LocalStorage

## Funcionalidades

- Página de inicio con presentación de la marca
- Catálogo de productos dinámico desde API
- Vista de detalle de producto con control de stock
- Carrito de compras interactivo
- Aumentar y disminuir cantidades
- Eliminar productos del carrito y vaciado total
- Persistencia del carrito en LocalStorage
- Switcher de tema claro / oscuro (Dark Mode)
- Formulario de compra controlado con validación de datos
- Confirmación de compra simulada mediante modal
- Notificaciones en tiempo real (Toast feedback)
- Diseño responsive adaptado a móviles y escritorio
